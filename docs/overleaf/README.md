# Relatório Overleaf

Esta pasta contém o relatório técnico completo do projeto VSSS Coach.

Para importar no Overleaf:

1. compacte `main.tex` e `references.bib` em um arquivo ZIP;
2. use **New Project > Upload Project**;
3. selecione `main.tex` como documento principal, se necessário;
4. compile com pdfLaTeX e BibTeX.

O relatório deve ser atualizado sempre que houver alterações em:

- mensagens ou portas do TraveSim;
- variáveis fornecidas à programação genética;
- primitivas matemáticas;
- limites físicos do controlador;
- formato do torneio ou função de aptidão.
